# Beauty Games 2026 — лендінг

Сайт міжнародного онлайн-реаліті для б'юті-майстрів: бізнес-програма, командні
змагання, реаліті-шоу та онлайн-чемпіонат. Сезон 2026.

Статичний сайт без збірки та залежностей — відкривається як є, розгортається
будь-де: GitHub Pages, Netlify, Vercel, звичайний хостинг.

---

## Сторінки

| Файл | Адреса | Для кого | Ціль |
|---|---|---|---|
| `index.html` | `/` | Майстрині | Заявка на участь у шоу та бізнес-програмі |
| `partners.html` | `/partners.html` | Бренди, спікери, судді | Заявка на співпрацю |

Акцент розрізняє аудиторії: головна — фірмова маджента `#E6007E`,
сторінка партнерів — неоновий ціан `#00FFFF`. Перемикач між ними — у шапці обох сторінок.

## Файли

```
index.html      головна сторінка — 19 блоків
partners.html   сторінка партнерам і спонсорам — 13 блоків
styles.css      дизайн-система: токени, скло, блум, компоненти, адаптив
app.js          інтерактив: меню, таймер, акордеони, таблиці, форма
fx.js           звукові ефекти (Web Audio API) і текстові ефекти
```

## Локальний запуск

Відкрити `index.html` у браузері достатньо для перегляду. Щоб усе працювало
коректно (відносні шляхи, `localStorage`), краще підняти локальний сервер:

```bash
python -m http.server 8000
```

Далі — `http://localhost:8000`.

## Дизайн-система

База — логобук проєкту (дизайнерка Marianna Halushka).

| Колір | HEX | Роль |
|---|---|---|
| Black | `#000000` | Основне тло |
| White | `#FFFFFF` | Заголовки, спекуляр на склі |
| Electric Magenta | `#E6007E` | Головне світло: блум, кнопки, акценти |
| Neon Cyan | `#00FFFF` | Друге світло: сторінка партнерів |
| Neon Lime | `#00FF00` | Тільки позначки «включено» в таблицях |
| Neon Yellow | `#FFFF00` | Точково: таймер, лічильники місць |

Шрифти: **Montserrat** (заголовки, інтерфейс) і **Manrope** (текст) з Google Fonts,
**JetBrains Mono** для технічних підписів. Логобук передбачає **Cy Grotesk Grand (Demi)**
для заголовків — якщо буде куплена веб-ліцензія, замінити у `styles.css`
змінну сімейства заголовків.

Матеріал інтерфейсу — «рідке скло»: `backdrop-filter`, спекулярний відблиск,
блум з-під нижнього краю акцентного елемента. Правила стриманості:
**один блум на екран**, текст ніколи не лежить на блумі, довгі списки й таблиці —
на спокійному склі без світіння.

## Що треба підключити

### 1. Відправка форми

У `fx.js` і `app.js` форма валідується на клієнті й показує екран успіху,
але **нікуди не відправляється**. Точка інтеграції позначена в `app.js`
коментарем `ТОЧКА ІНТЕГРАЦІЇ`. Там уже зібрано об'єкт `data` з усіма полями,
UTM-мітками та реферером. Підключити:

1. `POST` у CRM (KeyCRM або Pipedrive) — створення угоди з тегом пакета
2. Сповіщення в Telegram-бот менеджера
3. Лист заявниці з програмою сезону в PDF
4. Події аналітики — заготовки для `gtag` і `fbq` уже стоять

### 2. Аналітика

GA4, Meta Pixel і TikTok Pixel — додати скрипти в `<head>` обох сторінок.
Події, які вже відправляються з коду: `form_submit`, `Lead`.

### 3. Юридичні сторінки

Публічна оферта й політика конфіденційності — посилання у футері
поки ведуть на `#`. Для трафіку з ЄС також потрібен банер згоди на cookie.

### 4. Контент

У розмітці стоять підписані заглушки — видно, що саме й якого розміру потрібно:

- портрети спікерів і суддів — 800×800, однакове кадрування, темне тло
- фото засновниць — студійні, на темному тлі
- логотипи партнерів — вектор, монохром для темного тла
- відеовідгуки — 3 шт., 30–60 сек
- відео-трейлер для першого екрана

## Звук

Звукові ефекти синтезуються через Web Audio API — **жодних аудіофайлів**.
Вимкнені за замовчуванням, вмикаються кнопкою в шапці, вибір запам'ятовується
в `localStorage`.

Це навмисно: браузери блокують автоплей до першої взаємодії, а сайт часто
відкривають з Instagram у дорозі або поруч із клієнтом. Сайт, який раптово
заграв, закривають.

Усі звукові й текстові ефекти вимикаються при `prefers-reduced-motion`.

## Відкриті питання по контенту

Ці розбіжності знайдені у вихідних матеріалах проєкту. На сайті зараз стоїть
остання відома версія — перед запуском варто звірити:

1. **Дати сезону.** У матеріалах фігурують «старт 11.09.2026», «осінь 2026»
   і «червень–вересень». На сайті — «осінь 2026». Точна дата підсилить таймер.
2. **Гран-прі та Джекпот** описані без змісту. Це найсильніший аргумент
   сторінки, і він поки порожній — потрібна хоча б вилка суми.
3. **Місце проведення Гранд-Фіналу** не вказане. Країна й місто прямо впливають
   на рішення про VIP-пакет: людині треба планувати переліт і візу.
4. **Кількість категорій чемпіонату:** 8 у спонсорській презентації проти 10
   у тарифах. На сайті — 10.
5. **Тривалість проєкту:** 2 місяці проти 4 місяців (2 передпідготовки + 2 активної фази).
   На сайті — 4.
