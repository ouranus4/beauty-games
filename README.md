# Beauty Games 2026 — лендінг

Сайт міжнародного онлайн-реаліті для б'юті-майстрів: бізнес-програма, командні
змагання, реаліті-шоу та онлайн-чемпіонат. Сезон 2026.

Статичний сайт без збірки та залежностей — ані фреймворків, ані npm.
Розгорнутий на Netlify, заявки приймаються без окремого бекенду.

---

## Сторінки

| Файл | Адреса | Для кого | Ціль |
|---|---|---|---|
| `index.html` | `/` | Майстрині | Заявка на участь у шоу та бізнес-програмі |
| `partners.html` | `/partners.html` | Бренди, спікери, судді | Заявка на співпрацю |

Акцент розрізняє аудиторії: головна — фірмова маджента `#E6007E`,
сторінка партнерів — неоновий ціан `#00FFFF`. Перемикач між ними — у шапці обох сторінок.

## Файли

```

```

## Розгортання

Хостинг — **Netlify**. Підключення разове:

1. [app.netlify.com](https://app.netlify.com) → Add new site → Import an existing project
2. Deploy with GitHub → обрати репозиторій `ouranus4/beauty-games`
3. Build command залишити порожнім, Publish directory — `.`
4. Deploy

Далі кожен пуш у `main` розгортається автоматично. Налаштування хостингу —
у `netlify.toml`: коротка адреса `/partners`, заголовки безпеки, політика кешу.

Чому Netlify, а не Vercel: безкоштовний тариф Vercel (Hobby) за умовами
призначений для особистих некомерційних проєктів, а Beauty Games продає
пакети. У Netlify безкоштовний тариф комерцію дозволяє — і має вбудовані форми.

## Локальний запуск

Відкрити `index.html` у браузері достатньо для перегляду. Щоб усе працювало
коректно (відносні шляхи, `localStorage`), краще підняти локальний сервер:

```bash
python -m http.server 8000
```

Далі — `http://localhost:8000`.

## Дизайн-система

База — логобук проєкту (дизайнерка Marianna Halushka).

| Колір | HEX | Роль |
|---|---|---|
| Black | `#000000` | Основне тло |
| White | `#FFFFFF` | Заголовки, спекуляр на склі |
| Electric Magenta | `#E6007E` | Головне світло: блум, кнопки, акценти |
| Neon Cyan | `#00FFFF` | Друге світло: сторінка партнерів |
| Neon Lime | `#00FF00` | Тільки позначки «включено» в таблицях |
| Neon Yellow | `#FFFF00` | Точково: таймер, лічильники місць |

Шрифти: **Montserrat** (заголовки, інтерфейс) і **Manrope** (текст) з Google Fonts,
**JetBrains Mono** для технічних підписів. Логобук передбачає **Cy Grotesk Grand (Demi)**
для заголовків — якщо буде куплена веб-ліцензія, замінити у `styles.css`
змінну сімейства заголовків.

Матеріал інтерфейсу — «рідке скло»: `backdrop-filter`, спекулярний відблиск,
блум з-під нижнього краю акцентного елемента. Правила стриманості:
**один блум на екран**, текст ніколи не лежить на блумі, довгі списки й таблиці —
на спокійному склі без світіння.

## Що треба підключити

### 1. Заявки з форм

Форми вже підключені до **Netlify Forms** — окремий бекенд не потрібен,
і жодні токени в браузер не потрапляють. На сайті дві форми:

| Форма | Сторінка | Назва в Netlify |
|---|---|---|
| Участь у сезоні | `index.html` | `participant` |
| Співпраця, спікери, судді | `partners.html` | `partner` |

Заявки видно в панелі Netlify → **Forms**. Разом з полями форми надходять
`page`, `utm` і `referrer` — джерело трафіку видно одразу. Спам відсікається
прихованим полем-пасткою `bot-field`.

**Що налаштувати після першого деплою:**

1. Netlify → Forms → Notifications → **Email notification**, щоб заявки
   падали на пошту менеджера. Це мінімум, з яким можна працювати.
2. Там же → **Outgoing webhook** → адреса сценарію Make або Zapier, який
   створює угоду в CRM (KeyCRM, Pipedrive) і пише менеджеру в Telegram.
   Токени лежать у сценарії, а не в коді сайту.
3. Безкоштовний тариф — 100 заявок на місяць. За потоком варто стежити
   і за потреби підняти тариф, інакше заявки почнуть губитися.

Локально й на будь-якому іншому хостингу форма покаже екран успіху, але
нікуди не відправиться — запит тихо впаде в консоль. Це очікувано.

### 2. Аналітика

GA4, Meta Pixel і TikTok Pixel — додати скрипти в `<head>` обох сторінок.
Події, які вже відправляються з коду: `form_submit`, `Lead`.

### 3. Юридичні сторінки

Публічна оферта й політика конфіденційності — посилання у футері
поки ведуть на `#`. Для трафіку з ЄС також потрібен банер згоди на cookie.

### 4. Контент

У розмітці стоять підписані заглушки — видно, що саме й якого розміру потрібно:

- портрети спікерів і суддів — 800×800, однакове кадрування, темне тло
- фото засновниць — студійні, на темному тлі
- логотипи партнерів — вектор, монохром для темного тла
- відеовідгуки — 3 шт., 30–60 сек
- відео-трейлер для першого екрана

## Іконки та інфографіка

22 іконки живуть одним SVG-спрайтом просто в розмітці сторінок. Джерело
правди — `_sprite.py`: іконки описані там, а скрипт перезбирає блок
`<!-- SPRITE --> ... <!-- /SPRITE -->` в обох сторінках, щоб вони не
розходились. Після правок:

```bash
python _sprite.py
```

Вставляється іконка так:

```html
<svg class="icon" aria-hidden="true"><use href="#i-brow"/></svg>
```

Заливка береться з градієнтів `gIce` (маджента) і `gGold` (нагороди),
описаних у тому ж спрайті, тож іконки автоматично в брендових кольорах.

**Якщо захочете 3D-іконки.** Плоскі SVG можна замінити растровими
рендерами — у теці з референсами лежать промпти для Recraft та Ideogram.
Для темного тла просіть рендер **на чорному фоні**, інакше навколо іконки
буде світлий прямокутник. Замінюється точково: `<svg class="icon">` на
`<img class="icon" src="assets/icons/brow.webp" alt="">`.

Інфографіка — три блоки на головній: структура сезону, схема ліг і шлях
у фінал, розподіл місць у потоці. Усе намальовано інлайн-SVG у розмітці,
без бібліотек.

## Прелоадер

Світлове кільце, з якого проявляється знак проєкту. Ховається **CSS-анімацією**,
тож навіть якщо скрипт не виконається, сторінка не залишиться перекритою.
`app.js` лише прибирає його з DOM після завантаження і має страховку на 4 секунди.

## Звук

Звукові ефекти синтезуються через Web Audio API — **жодних аудіофайлів**.
Вимкнені за замовчуванням, вмикаються кнопкою в шапці, вибір запам'ятовується
в `localStorage`.

Це навмисно: браузери блокують автоплей до першої взаємодії, а сайт часто
відкривають з Instagram у дорозі або поруч із клієнтом. Сайт, який раптово
заграв, закривають.

На мобільних є дві особливості, які враховані в коді: iOS глушить Web Audio
при увімкненому беззвучному режимі (лікується `navigator.audioSession`),
а сам контекст засинає після дзвінка чи блокування екрана — тому він
будиться на кожній дії та при поверненні на вкладку.

Усі звукові й текстові ефекти вимикаються при `prefers-reduced-motion`.

## Відкриті питання по контенту

Ці розбіжності знайдені у вихідних матеріалах проєкту. На сайті зараз стоїть
остання відома версія — перед запуском варто звірити:

1. **Дати сезону.** У матеріалах фігурують «старт 11.09.2026», «осінь 2026»
   і «червень–вересень». На сайті — «осінь 2026». Точна дата підсилить таймер.
2. **Гран-прі та Джекпот** описані без змісту. Це найсильніший аргумент
   сторінки, і він поки порожній — потрібна хоча б вилка суми.
3. **Місце проведення Гранд-Фіналу** не вказане. Країна й місто прямо впливають
   на рішення про VIP-пакет: людині треба планувати переліт і візу.
4. **Кількість категорій чемпіонату:** 8 у спонсорській презентації проти 10
   у тарифах. На сайті — 10.
5. **Тривалість проєкту:** 2 місяці проти 4 місяців (2 передпідготовки + 2 активної фази).
   На сайті — 4.
